# Course progress archive

This directory contains code snapshots and terminal output from individual
steps of the IBM course assignment. These files are retained as supporting
material and are not imported or executed by the application.

The maintained implementation is located in:

- `EmotionDetection/emotion_detection.py`
- `server.py`
- `static/mywebscript.js`
- `templates/index.html`

Automated tests are located in `tests/`.
